設定のしかた
1. GitHubで、記録専用の「プライベート」リポジトリを新しく作ります（例：workout-data）。公開（Public）にはしないでください。
2. GitHubの Settings → Developer settings → Personal access tokens → Fine-grained tokens で、新しいトークンを作ります。対象はそのリポジトリだけ、権限は Contents: Read and write だけにします。
3. 上の欄に「ユーザー名/リポジトリ名」とトークンを入れて「接続」を押します。2台目以降の端末も、同じ手順で接続します。
トークンは、この端末のブラウザにだけ保存されます。
削除すると元に戻せません。
